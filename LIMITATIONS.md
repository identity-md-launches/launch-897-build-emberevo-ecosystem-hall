# Limitations

- **E1 only.** The site is a working static reading and comparison frontend. All shipped projects, evidence, commercial relationships and approval declarations are synthetic DEMO_DATA.
- **E2 pending:** live data retrieval, research/model execution, source verification, authenticated publisher approvals, durable append-only publication/withdrawal records and a production backend. The read-only HTTP adapter is implemented and tested against a local mock; no live backend is claimed.
- **E3 pending:** ongoing monitoring, change detection, scheduling and alert delivery. No subscriptions, recurring jobs, paid calls, accounts or secrets are created.
- **World integration pending:** the only World destination is `https://imdember.com/`. No character/camera restore, world wiring, session data or arbitrary returnUrl. Genesis PEPE and Dream Hall remain future integration contexts.
- No wallet, SSO, ownership, mint/burn/swap/staking/payment or NFT entitlement logic. Future Paid Genesis context is EMVO paid to an owner-confirmed Paying Wallet with no required burn. No price, wallet address or implementation is supplied.
- No supplied logo or attachment was available. Text wordmark is intentional; logo integration is pending. No IMD Radar assets or private world source were used.
- The demo source links point to the reserved example.org domain and explicitly do not substantiate the fictional claims. No fake Swarm, audit or onchain histories are provided.
- Browser storage is a defense against this device reusing an already withdrawn revision, not a trusted publication ledger. It cannot detect an authoritative server lying, unknown prior withdrawals, cleared local storage or storage modified outside the app. Reports are never restored as current from cache.
- Browser-native Web Crypto requires a secure context (HTTPS or loopback). IPFS should use an HTTPS gateway. Opening index.html as a local file is unsupported.
- Pagination is manual and search covers only loaded bundles. Missing research remains empty. No site-wide backend search, asset conversion, liquidity inference, safety score or certification exists.
- The delivered UI is Traditional Chinese only, with English identifiers. CJK font appearance depends on locally available system fonts. There are no remote font downloads.
- Browser verification uses Chromium on Linux, not physical devices. Screen-reader sessions, Safari/Firefox, native 200% zoom and production-host checks are NOT_RUN. 320px reflow and reduced-motion emulation are tested separately and do not substitute for those checks.
- **Public publication pending.** There is no public repo/commit/preview for this artifact yet. No remote was configured, no authenticated publication tool supplied, and `.git/` changes were prohibited. The static export and source are ready for the enclosing submission/publishing step. Local preview URLs in evidence are temporary and are not public deployment URLs.
